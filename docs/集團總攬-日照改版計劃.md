# 集團總覽 - 日照改版計劃

> 根據 Figma 設計稿 & 現有程式碼架構分析，供確認後動工。
> 最後更新：2026-05-14

---

## 一、目標

在左側 Menu 新增「日照」入口，頁面分為：
- **總覽**：跨機構彙總數據（對應 Figma「日照總覽」大標題底下內容）
- **各機構**：每間日照中心的個別數據（對應 Figma「機構項目」大標題底下內容）

每個內容卡片支援分享（複製連結 + 下載圖片）。Tab 狀態記憶於 URL，方便連結分享。

---

## 二、頁面切換設計（Material Design 原則）

### 桌面（md+ ≥ 900px）：水平 Tabs

```
左側 Menu
└── 日照  →  /daycare

頁面頂部 Tabs（可橫向捲動，不限機構數）：
┌─────────────────────────────────────────────────────────┐
│  總覽  │  博愛日照中心  │  樂活日照中心  │  信義日照中心  ◀▶ │
└─────────────────────────────────────────────────────────┘
```

- MUI `<Tabs variant="scrollable" scrollButtons="auto">`
- 機構再多也不會換行或截斷，使用者左右滑動即可
- 符合 Material Design Tabs 的橫向導覽語意

### 手機 / 平板（xs–sm < 900px）：Select 下拉選單

```
┌──────────────────────────────────┐
│ 📍 博愛日照中心              ▼  │
└──────────────────────────────────┘
```

- MUI `<Select>` 取代 Tabs，不受機構數量限制
- 無論 2 間或 20 間，UI 不會崩潰或擠壓
- 點選後彈出原生 select / MUI 下拉，選項顯示全名
- 比橫向捲動 Tabs 在手機上更好操作（觸控面積大、不需精準滑動）

**切換邏輯實作（`useMediaQuery` + 同一狀態）：**

```jsx
const isMobile = useMediaQuery(theme.breakpoints.down('md'))
const [tab, setTab] = useSearchParams()  // ?tab=overview 或 ?tab=dc-01

// 桌面：<Tabs value={currentTab} onChange={...}>
// 手機：<Select value={currentTab} onChange={...}>
// 兩者共用同一個 tab state
```

## 三、URL 記憶與分享

### Tab 狀態記憶

使用 `useSearchParams`（現有 `Capacity.jsx` 已採用此模式）：

| 狀態 | URL |
|------|-----|
| 總覽 Tab | `/daycare?tab=overview` |
| 博愛機構 Tab | `/daycare?tab=dc-01` |
| 樂活機構 Tab | `/daycare?tab=dc-02` |

首次進入無參數時，預設導向 `?tab=overview`。

### 卡片分享（Section 分享）

URL + section anchor，方便分享到特定區塊：

```
/daycare?tab=dc-01#attendance-trend
/daycare?tab=dc-01#financial-snapshot
```

## 五、分享功能設計

### 入口：卡片右上角小圖示

每個 Section Card 的 header 右側放一個 `IosShareIcon`（MUI），尺寸 small，灰色低調：

```
┌─────────────────────────────────────┐
│  出席率趨勢（近 6 個月）        ⬆️  │  ← 分享圖示
│  ─────────────────────────────────  │
│  [圖表內容]                         │
└─────────────────────────────────────┘
```

### 點擊後：MUI Popover 選單

```
┌──────────────┐
│ 🔗 複製連結  │  ← 複製 ?tab=dc-01#attendance-trend
│ 📷 下載圖片  │  ← 截圖此卡片為 PNG
└──────────────┘
```

### 複製連結（無需新套件）

```js
const shareUrl = `${window.location.origin}${window.location.pathname}?tab=${currentTab}#${sectionId}`
navigator.clipboard.writeText(shareUrl)
// 複製後顯示短暫 Snackbar：「連結已複製」
```

### 下載圖片（需新增 `html2canvas`）

```js
import html2canvas from 'html2canvas'
const canvas = await html2canvas(sectionRef.current)
// 觸發下載 PNG
```

> ⚠️ **新依賴確認**：`html2canvas`（~50KB gzip，無子依賴）需確認是否可加入。
> 若不採用，可改為：手機端觸發 `navigator.share()`（Web Share API，僅限 HTTPS + 支援的瀏覽器），桌面端只提供複製連結。

### 手機補充：Web Share API

手機瀏覽器如支援 `navigator.share`（iOS Safari、Android Chrome），點「下載圖片」改為呼叫系統分享選單（可分享到 LINE、Email 等），體驗更原生：

```js
if (navigator.share) {
  await navigator.share({ title: '出席率趨勢', url: shareUrl })
} else {
  // 降級：複製連結
}
```

## 八、RWD 規格

### 導覽元件

| 斷點 | 機構切換元件 | 說明 |
|------|-------------|------|
| xs–sm（< 900px） | MUI `<Select>` 下拉 | 不受機構數量限制，觸控友善 |
| md+（≥ 900px） | MUI `<Tabs variant="scrollable">` | 可橫向捲動，支援任意數量 |

### 內容 Grid

| 斷點 | 佈局 |
|------|------|
| xs（< 600px） | 單欄（`size={12}`） |
| sm（600–900px） | 雙欄（`size={6}`） |
| md+（> 900px） | 依區塊設計：KPI 三欄、圖表二欄 |

> KPI 卡片：xs=12 / sm=6 / md=4，與現有 `Dashboard.jsx` 相同。
